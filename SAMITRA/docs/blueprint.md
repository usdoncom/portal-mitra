# **App Name**: Portal Mitra

## Core Features:

- Intelligent Submission Guide Tool: An AI-powered tool that uses reasoning to recommend the specific Google Form a partner needs based on their textual description of a business scenario or problem.
- Categorized Form Hub: A streamlined navigation interface organizing services into Pengajuan Dokumen, Marketing, Event, Kemitraan, and Merchandise.
- Live Service Search: A rapid-filtering search bar allowing partners to quickly locate specific forms like the 'Surat Keterangan Umroh' or 'Landing Page Order' by name.
- Responsive Service Cards: Clean, card-based displays for each service (e.g., Pendaftaran Seminar) with deep-linking to provided Google Form URLs.
- Direct Apply Gateway: Single-action buttons labeled 'Ajukan Sekarang' that handle seamless external redirection to dedicated forms such as https://forms.gle/919jxKEAjfiC8xd6A.
- Admin WhatsApp Integration: A persistent contact trigger for immediate partner assistance via a floating action button or footer link.
- Mobile-First Navigation System: A tailored layout specifically designed for smartphones to ensure high-priority access to form links while on the move.

## Style Guidelines:

- Primary color: Deep Forest Green (#0D3D29) to evoke professional trust and reliability.
- Background color: Mint Tint White (#F3F7F5) to keep the interface light and clean for mobile use.
- Accent color: Burnished Gold (#B8860B) used for 'Ajukan Sekarang' call-to-action buttons to create a prestigious, high-end feel.
- Headline font: 'Playfair' (serif) for a sophisticated and established corporate look.
- Body font: 'PT Sans' (sans-serif) for optimal legibility across varying mobile screen resolutions.
- A clean single-column card stack on mobile that expands to a grid on tablets, emphasizing white space and vertical rhythm.
- Soft micro-interactions like subtle elevation gains on service cards when tapped or hovered.
